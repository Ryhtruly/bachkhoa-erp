# Contract Template Selection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users choose a published private DOCX template for a new contract and always render that contract with its chosen template.

**Architecture:** `contract_templates` remains the versioned catalog and stores only a private object key. Add nullable `contracts.contract_template_id` to persist the selected catalog row; creation validates that selection is published, while document rendering loads that exact row. Legacy contracts with no selection retain the existing fallback during migration.

**Tech Stack:** Supabase PostgreSQL, FastAPI, SQLAlchemy, Pydantic, React/Vite/Vitest, MinIO/Cloudflare R2, pytest.

## Global Constraints

- Keep objects private; never return storage credentials or a public object URL to the browser.
- Use immutable keys: `contract-templates/HOP_DONG_DICH_VU_KHUNG_BACH_KHOA/v1.docx` and `contract-templates/MAU_HOP_DONG_DO_DAC_BACH_KHOA/v1.docx`.
- Permit selection only of `published` templates, but allow an already-selected archived template to render historical contracts.
- Keep `contract_template_id` nullable for legacy contracts in this release.
- Backend tests must set a local disposable `TEST_DATABASE_URL` ending in `_test`; never use Supabase or the application `DATABASE_URL`.
- Before changing a function, class, or method, run GitNexus upstream impact analysis and report HIGH/CRITICAL risk.

In `services.py`, import `ContractTemplate` and implement:

```python
def resolve_published_contract_template(db: Session, template_id: str) -> ContractTemplate:
    template = (
        db.query(ContractTemplate)
        .filter(
            ContractTemplate.id == template_id,
            ContractTemplate.status == "published",
        )
        .first()
    )
    if not template:
        raise HTTPException(status_code=422, detail="Mẫu hợp đồng không tồn tại hoặc chưa được ban hành")
    if not template.template_storage_key:
        raise HTTPException(status_code=422, detail="Mẫu hợp đồng chưa có tệp DOCX riêng tư")
    return template
```

Call it before any customer, contract, receivable, audit, or workflow write in both service methods. Assign `contract_template_id=template.id` to each new `Contract`; assign `template_id=template.id` to `ContractGeneratedDocument`.

- [ ] **Step 3: Add the protected catalog endpoint.**

Place this static endpoint before parameterized routes:

```python
@router.get("/templates")
def list_published_contract_templates(
    db: Session = Depends(get_db),
    _: User = Depends(require_permission("contract", "create")),
):
    rows = (
        db.query(ContractTemplate)
        .filter(ContractTemplate.status == "published")
        .order_by(ContractTemplate.code.asc(), ContractTemplate.version.desc())
        .all()
    )
    return [
        {"id": row.id, "code": row.code, "version": row.version, "name": row.name}
        for row in rows
    ]
```
